# 产物样式规范（doc-to-html）

本文件供 agent 在需要**手工增强**转换产物时参考。默认情况下脚本输出已满足规范，无需手工干预。

## 布局

- 单文件 HTML，`<nav class="sidebar">`（272px 固定侧栏：标题 + 目录）+ `.main > .wrap`（最大 940px 内容列）。
- 目录只收录 h2（一级）与 h3（缩进二级），标签超 28 字符截断加 `…`。
- 主题色通过 CSS 变量 `--accent`（默认 `#4f46e5`）与渐变伙伴 `--accent2`（`#8b5cf6`）控制；标题下渐变短横条、目录高亮、链接色均引用它们。

## 内容元素

- **表格**：脚本会包 `.tw` 容器（圆角 + 横向滚动），无需手工处理；单元格内代码自动缩小。
- **代码块**：语言标记 ` ```sql / ```json / ```bash / ```python / ```js` 等会触发轻量高亮（关键字紫、字符串绿、注释灰斜体）；mermaid 输出为 `pre.mermaid-src` 虚线框源码块。
- **引用块**：淡靛蓝底 + 左侧竖线；文档头部的长元信息/修订 blockquote 会被折叠为 `details.docmeta`。
- **图片**：默认 base64 内嵌并 `loading="lazy"`；正文预览适应内容宽度和屏幕高度，点击图片或“查看大图”进入占满浏览器窗口的独立预览。初始适应屏幕，支持原尺寸、按钮/滚轮/捏合缩放、鼠标/触摸拖动；关闭或按 Esc 回到原阅读位置。普通图片由脚本自动处理，带链接的图片保留原跳转；缺失图片带 `img-missing` 虚线占位样式。不要手工加入正文框内的原尺寸滚动开关；旧 `.source-panel` 控件由预览脚本替换。

## 手绘核心图表（替代 mermaid 源码块）

当某张 mermaid 图是全文核心配图时，可用纯 HTML/CSS 重绘为静态图（离线可渲染），替换对应 `<pre class="mermaid-src">` 块：

- **时序图骨架**：`.seq` 容器（淡靛蓝渐变底、圆角 16、内边距 22）→ `.seq-actors`（三等分网格，参与者为圆角描边芯片）→ `.seq-body`（三等分网格 + 三个 `i.ll` 虚线生命线，位于 16.67% / 50% / 83.33%）。
- **消息行**：`.smsg`（grid-column 跨列），标签 `.lbl` 在上行居中，`.line` 绝对定位在行底部（`left:16.67%;right:16.67%` 跨三列；两列时 `left:25%;right:25%`），`::after` 三角箭头，`.rl` 加 `transform:scaleX(-1)` 反向，`.dash` 虚线。
- **自消息/备注**：`.ss` / `.snote` 居中圆角芯片（备注用虚线边框）；**阶段横幅** `.sspan` 全宽浅靛蓝条。
- 关键约束：标签放普通流内（保证行高自适应），仅线条绝对定位；配色从 `--accent` 派生，勿引入新色相。

## 打印与响应式

- 打印：隐藏侧栏、回顶按钮、大图预览与“查看大图”按钮；正文图片取消高度限制，取消横向滚动、`details.docmeta` 强制展开、`h2 break-after:avoid`、`tr/pre break-inside:avoid`。
- 窄屏（≤1020px）：侧栏变静态、目录隐藏、主区全宽。
